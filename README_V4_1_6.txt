CHAPA ID V4.1.6

Correção: páginas sem Cod. Interno não viram erro automaticamente.
Regra de identificação do código:
1. Se existir Cod. Interno no mesmo bloco visual do H1 do produto, ele continua sendo a chave principal.
2. Se não existir Cod. Interno, o sistema procura Cód. LM-... no mesmo bloco visual do H1 e usa esse código como identificador alternativo.
3. Nunca mistura Cód. LM de cards/recomendações com o produto atual.
4. Anti-colisão e validação de descrição continuam ativos.
5. Interface diferencia COD. INTERNO e CÓD. LM.

Exemplo suportado: Cód. LM-FBSRR100800-A021.
